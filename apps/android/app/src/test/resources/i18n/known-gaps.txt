# Écarts de localisation connus — un CLIQUET (LocalizationGuardTest).
#
# Une ligne = un écart que la garde constate aujourd'hui et qu'un lot ultérieur doit combler :
#   <règle> <module> <locale> <clé>      (« - » quand le champ est sans objet)
# Le test échoue dans les DEUX sens : un écart constaté qui n'est pas ici est un NOUVEL écart
# (le corriger, ou consigner sa ligne en le disant), et une ligne d'ici qui n'est plus vraie
# est périmée (la retirer). Le fichier ne peut donc que rétrécir. Les lignes à ajouter sont
# imprimées par le test lui-même.

# --- Langue déclarée dans l'app sans aucune ressource ---------------------------------------
# ar est dans AppLanguage.supportedCodes (sélecteur de langue d'interface) mais aucun module
# ne livre values-ar : choisir l'arabe laisse l'interface en anglais. Comblé par le lot qui
# génère les ressources des sept langues depuis les catalogues iOS (./apps/android/meeshy.sh i18n).
