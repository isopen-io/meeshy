Méthode. Une issue est « livrée » quand elle est fermée sur GitHub (le projet passe alors son Status à Done). Le pourcentage rapporte les issues livrées à toutes les issues du projet, y compris les 94 lignes de la planche MeeshyComposer déjà livrées. Les horizons sont les versions cibles de la roadmap ; l'échéance d'un horizon est celle de ses milestones.

Lecture. Les 115 fermetures du 26 août 2026 correspondent à la bascule de la planche dans le projet : la courbe par jour ne parle qu'à partir du 27 août. En cas d'écart, l'issue GitHub fait foi.
