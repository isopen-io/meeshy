06 · Les règles du kit

Cinq règles, tenues sur chaque fiche

[[ic:atom l]]

Un atome agnostique

Paramètres opaques, aucun type « profil », aucun singleton Meeshy. L'orchestration reste côté app.

[[ic:magnifying-glass l]]

On extrait avant de créer

Le jumeau le plus complet déjà dans le code devient le composant.

[[ic:devices l]]

Mêmes noms partout

Une seule API sur les trois plateformes : iOS SwiftUI, Android Compose, Web Preact.

[[ic:cube-transparent l]]

Le verre a une entrée

K01 seul décide : Liquid Glass sur iOS 26+, verre dessiné ailleurs, surface tonale sur Android.

[[ic:list-checks l]]

Recette, jetons, témoins

Chaque composant a sa recette en valeurs …Recipe, ses jetons et ses tests.
