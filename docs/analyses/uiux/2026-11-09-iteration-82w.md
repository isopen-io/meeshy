## Défaut (cohérence de thème / maintenabilité) : l'écran d'humeur peint son chrome immersif en littéraux bruts

La page d'une humeur reçue (`components/mood-page.tsx`, #10813) est un **plein
écran posé SUR un média** : la bannière de l'auteur (photo, design, ou dégradé de
son accent) voilée, son avatar dans un halo, son mot en encre claire. Chacune de
ces couleurs a un **RÔLE que la charte nomme déjà** (`docs/product/charte-visuelle-web.md`) :
encre sur média (`on-media`), encre sur aplat de marque (`ios-on-brand`), voiles
(`scrim-soft` / `scrim`), assombrissement vers le fond média (`media-backdrop`),
halo blanc (`on-media-2`). Mais le fichier les écrivait **en dur** — `text-white`
×4, `rgb(0 0 0 / …)` ×6, `rgb(255 255 255 / 0.85)`, `black` ×2, `'white'` — soit
**13 des 27 violations du gate d'harmonie (48 %)**, et la plus grosse poche de
chrome du produit web.

C'est exactement le défaut que le gate existe pour attraper (#8879, directive
porteur 2026-09-30) : « le même voile noir vaut 35, 40, 45, 50, 55 % selon
l'écran » — ici un même écran portait 0.35, 0.15, 0.45, 0.55 côte à côte.

## Correctif (TDD)

- **RED** : deux témoins ajoutés à `scripts/check-design-harmony.test.ts`
  (describe « l'écran d'humeur ») lisant la VRAIE source par l'API publique du
  gate — `scanSource(mood-page.tsx)` doit rendre `[]`, et le fichier doit porter
  les jetons (`text-on-media`, `var(--color-scrim…)`, `var(--color-media-backdrop)`)
  sans passer par une exemption. RED : 13 violations.
- **GREEN** : les 13 littéraux remplacés par leur jeton (table ci-dessus).
- **Témoin d'effet préservé** : `mood-page.test.tsx` asserte « sans bannière, un
  fond de repli ». happy-dom ne parse pas `color-mix(…, var(…))` et vidait la
  propriété ; le témoin atteste désormais la BRANCHE peinte par un marqueur
  `data-mood-backdrop-fill` (indépendant du parseur CSS), et vérifie qu'il est
  ABSENT quand une photo de bannière est servie — coverage renforcé, pas perdu.

## ✅ Statut : CORRIGÉ (iter-82w)

**NE PLUS re-signaler** les couleurs de `components/mood-page.tsx` : son chrome
immersif (encre sur média, voiles, halo, assombrissement d'accent) passe désormais

`data-mood-backdrop-fill` (happy-dom ne parse pas `color-mix(…, var(…))` : tester
la branche, pas la chaîne CSS).
