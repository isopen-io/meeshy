## Problème — un repli de jeton pris pour une couleur de chrome

Quatre styles inline écrivent `var(--jeton, littéral)` :

```tsx
// battery-panel.tsx:312 — bouton « confirmer » sur aplat de marque
color: 'var(--color-ios-on-brand, #fff)', backgroundColor: 'var(--color-ios-brand)'
// shared-location-card.tsx:34 — lien « ouvrir dans Plans » sur aplat de marque
backgroundColor: 'var(--color-brand)', color: 'var(--color-on-brand, #fff)'
// profile-relation-face.tsx:112 — carte du cercle de relation
backgroundColor: 'var(--color-ios-fill, rgba(127,127,127,.14))'
// vitrine-preview.tsx:71 — puce de capacité ouverte
backgroundColor: 'var(--color-ios-fill, rgba(127,127,127,.14))'
```

Le gate y voit `#fff` / `rgba(` — 4 des 9 violations. Mais le littéral n'est que
le **REPLI** d'un jeton **DÉCLARÉ** :

- `--color-ios-on-brand: var(--ios-on-brand)` (`src/styles/ios.css:56`, bloc `@theme inline`) ;
- `--color-on-brand: var(--color-on-primary)` (`src/styles/app.css:59`, bloc `@theme inline`) ;
- `--color-ios-fill: color-mix(in srgb, var(--ios-ink-3) 12%, transparent)` (`src/styles/ios.css:63`, bloc `@theme inline`).

`@theme inline` émet ces propriétés sur `:root` **sans condition** ; la garde
`src/styles/declared-tokens.test.ts` interdit qu'un jeton utilisé en style
inline soit absent de la table. Le littéral n'est donc **jamais rendu** en
pratique.

**Mais on le GARDE** — c'est un vrai filet de sécurité, pas du bruit. Pour les
deux boutons de marque, l'encre `color` repose sur un aplat `--color-*-brand`
saturé ; si le jeton d'encre manquait au montage (contexte isolé, CSS pas encore
chargé), `color: var(--token)` **sans repli** serait invalide → la propriété est
ignorée → l'encre **héritée** (potentiellement sombre) sur fond de marque =
texte **illisible**. Le repli `#fff` est donc du contraste défensif, pas une
couleur en dur du chrome.

## Correction (TDD)

1. **RED** — `describe("les replis d'un jeton de charte défini — un filet de
   contraste, jamais rendu")` dans `scripts/check-design-harmony.test.ts` :
   `scanSource(x) → []` pour les 4 fichiers + `exemptionOf(path) === null`
   (exemption **à la ligne**, pas par chemin) + le repli est **conservé**
   (`toContain('var(--…, …)')`). 2 tests RED (42 pass → 2 fail).
2. **GREEN** — un commentaire inline `/* harmony-exempt: repli d'un jeton de
   charte défini (--color-…), jamais rendu … */` sur chacune des 4 lignes de
   style, posé **dans l'objet `style`**, sur la même ligne que le littéral.
   **Aucun pixel ne change** : seuls des commentaires sont ajoutés, les styles
   restent bit pour bit les mêmes.

Pas un jeton de plus (il existe déjà et sert), pas un repli retiré (il protège le
contraste) : une **exemption motivée à la ligne**, le bon outil pour un repli de
jeton défini — le même régime que la rampe d'alpha de `face-rig` (89w) et le
masque de luminance de la famille appel (85w).
