## 1. Objet

Le présent contrat régit l'utilisation de l'application mobile Meeshy (« l'Application ») distribuée par [raison sociale de l'éditeur, adresse] (« l'Éditeur ») sur l'App Store d'Apple et sur Google Play.

## 2. Licence de l'Application : GNU Affero General Public License, version 3

L'Application intègre la bibliothèque libsignal (Signal Messenger, LLC), distribuée sous la GNU Affero General Public License, version 3 uniquement (« AGPL-3.0 »). L'Application, prise dans son ensemble, vous est donc concédée **sous les conditions de l'AGPL-3.0**, dont le texte intégral est :

- affiché dans l'Application (Réglages › À propos › Licences) ;
- publié à l'adresse https://www.gnu.org/licenses/agpl-3.0.html ;
- reproduit dans le fichier `LICENSES/AGPL-3.0.txt` du dépôt https://github.com/isopen-io/meeshy.

Le code source écrit pour Meeshy est en outre publié sous licence MIT ; cette licence vous accorde des droits plus larges sur ces fichiers pris isolément.

## 3. Code source

Le code source correspondant à chaque version de l'Application, y compris les scripts de construction, est disponible gratuitement à l'adresse https://github.com/isopen-io/meeshy, au commit exact indiqué dans l'Application (Réglages › À propos › Licences › Code source). Une copie sur support durable peut être demandée à [contact@meeshy.me], aux conditions de la section 6 de l'AGPL-3.0.
